ONKOSULLAR
───────────────────────────────
  - Node.js 22+ : https://nodejs.org/en/download (LTS secin)
  - Docker Desktop : https://www.docker.com/products/docker-desktop

  NOT: PostgreSQL otomatik olarak Docker container icinde
  calistirilir. Ayrica PostgreSQL kurmaniz gerekmez.

  Kontrol icin: ONKOSULLER_KONTROL.bat cift tiklayin.


KURULUM ADIMLARI (Tek seferlik)
───────────────────────────────
1. ONKOSULLER_KONTROL.bat cift tiklayin (Node.js + Docker kontrolu)
2. KURULUM.bat cift tiklayin (~5 dakika surer)
   - PostgreSQL container otomatik olusturulur
   - Bagimliliklar yuklenir
   - Veritabani tablolari olusturulur
   - Test verileri yuklenir
3. BASLAT.bat cift tiklayin
   Tarayici otomatik acilacak: http://localhost:3000

SORUN GIDERME
───────────────────────────────
- "Port kullanimda": BASLAT.bat yerine terminalde calistirin:
  npm run dev -- -p 3001

- Docker Desktop calismiyor:
  Docker Desktop uygulamasini acin ve bekleyin.

- PostgreSQL container bulunamadi:
  KURULUM.bat tekrar calistirin (container yeniden olusturulur).

- Veritabani sifirlama:
  npx prisma db push --force-reset
  npx tsx prisma/seed.ts
